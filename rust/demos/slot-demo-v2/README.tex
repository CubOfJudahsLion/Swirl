\section*{About}
This demo uses \textbf{SWIRL} to build a fa\c{c}ade for a slots machine. It has minimal business
logic, will spin/stop the reels at the user's request, and it'll highlight random symbols mocking
a winning line.

\section*{Building and Testing}
(See \filepath{\link{file://../../../README.pdf}{../../../README.pdf}} for the building process and requisites.)\\

Once the demo project is built, ensure your web server makes the \filepath{\link{file://./html}{html}} folder
available, and navigate to it. It's not possible to use a \texttt{file://} location as certain browsers prevent
local file reading and asset loading wouldn't work.
