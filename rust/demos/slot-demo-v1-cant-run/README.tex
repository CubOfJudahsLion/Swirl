\section*{About}
This demo uses \textbf{SWIRL} to build a fa\c{c}ade for a slots machine. The machine has no more
internal logic to it than spinning a fixed symbol distance, but it's enough for
displaying the possibilities of the library.

\section*{Building and Testing}
(See \filepath{\link{file://../../README.pdf}{../../README.pdf}} for the building process and requisites.)\\

Once the project is built, deploy the contents of the \texttt{./out} folder where it
can be displayed by a web server, and point your browser at it. It's not possible
to use a \texttt{file://} location as certain browsers prevent local file reading and
asset loading wouldn't work.
