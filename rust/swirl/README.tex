\section*{About}
\textbf{SWIRL} (\textbf{S}cene-graph \textbf{W}eb-oriented \textbf{I}ndependent
\textbf{R}endering \textbf{L}ibrary) is our in-house
\link{https://webassembly.org/}{WebAssembly}-based display library, written in the
\link{https://www.rust-lang.org/}{Rust} programming language. It organizes scene
elements and renders them directly using a \texttt{CanvasRenderingContext2d}. It uses
no intermediaries and depends on no other libraries than the basic
\link{https://crates.io/crates/wasm-bindgen}{wasm-bindgen} / \!\!
\link{https://crates.io/crates/js-sys}{js-sys} / \!\!
\link{https://crates.io/crates/web-sys}{web-sys} library set created by the
\textbf{Rust-WASM} team.\\
